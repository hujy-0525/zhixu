# 架构与数据边界

公开版是静态站点，数据流为：本机导入 → 解析 → IndexedDB → 讨论/证据卡 → 全文检索。
人物映射限定在会话内；关联人物不等于每句话都由该人物表达。

消息原始版本不可覆写。人工校订进入 messageEdits；当前显示使用最新校订。
证据记录 messageId、原始版本、校订版本、字符范围和逐字 quote。
修改消息会将使用该消息的已确认卡标回 draft；旧证据继续读取历史版本。

卡片区分表达类型（原话、转述、归纳、推断）、执行状态和人工审阅状态。
状态为决定/执行中/完成时，需要选择直接证据；规则会拒绝明显的建议、假设等表述。
这只是确定性防线，仍需人工审核含义。

公开站没有服务端数据库、模型调用和私人 MCP。static build 不含 worker/sync、身份服务、
私人项目配置和旧源码历史。私有版存在的云同步与只读 MCP 不是公开版的在线接口。

附件原始字节与 SHA-256 校验信息保存在本机。HTML 预览隔离脚本与外部资源；
PDF 在本机生成位图预览。重置示例先保留旧快照，不等同于永久删除。

本发行版要求部署在站点根路径；相对子目录托管需要调整资源路径。
