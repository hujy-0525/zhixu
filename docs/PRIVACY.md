# 公开发行版隐私检查

采用文件白名单重建，没有迁移私人工作区、旧 Git 历史、回退包、原始会议和身份配置。
人物 A/B/C、产品、评测附件、日期及对话均重新编写，非真实记录的替换姓名版本。
作者姓名与 GitHub 账号作为作品署名保留。

公开页面默认不读远端资料。OCR 会请求第三方 CDN 的引擎与语言资源，图片内容交给本机
Worker 处理；这不意味着浏览器的所有网络请求都为零。公开网页本身也会有托管访问日志。
无遥测与广告脚本；不要在公开站输入未经授权的敏感材料。

隐私扫描仅检查已知敏感模式，不能证明任何未来文件都不泄密。贡献新示例需要人工审查：
原话、数字、链接、二维码、文件元数据、附件内容、截图、密钥和 Git 历史。

发现问题时请勿在公开 Issue 张贴秘密或敏感证据；先删除本地副本的敏感信息再报告。
