# 知序 · Zhixu

**把零散聊天与文件，变成有来处的项目经验。**

以证据为中心的本机知识工作台：完整上下文 → 选择消息 → 项目脉络与人物情境观点 → 人工确认 → 带来源检索。

这是可独立运行的公开发行版与产品作品集，包含完全虚构的「星帆助手」案例。
私人云端版本独立部署，其云数据、认证配置、MCP、模型密钥与旧历史均不在本仓库。

## 30 秒看亮点

- **双线建模**：同一证据支持项目变化与人物情境观点。
- **状态校验**：建议、承诺、决定、执行中和完成分别处理；“建议验证”不能确认成“已完成”。
- **版本引用**：人工校订直接更新消息，旧引用保留历史版本，受影响确认卡回到待复核。
- **实际可操作**：消息导入、附件绑定、原件预览、讨论、证据卡、全文检索、备份恢复。
- **隐私隔离**：公开站无私人云接口；访客修改保存在自己的浏览器 IndexedDB。

## 运行

要求 Node.js 22+（本次验证使用 Node.js 24）。

```bash
npm ci
npm run build
npm run dev
```

打开 http://localhost:4173 。无 API Key、账号或数据库服务要求。

- `/`：产品作品集
- `/walkthrough.html`：完整证据工作流引导
- `/workspace.html`：预置虚构数据的完整本机工作台
- `/knowledge.html`：本机全文检索与上下文

```bash
npm test
npm run audit:privacy
```

## 体验一个案例

1. 查看 7 条虚构讨论和评测 HTML 附件。
2. 选择导师建议、产品决定，查看项目与人物双线草稿。
3. 将建议标为“已完成”，观察规则拒绝确认。
4. 改回“建议”，核对原文后确认。
5. 检索关键词，展开原消息前后文。
6. 人工校订来源，观察已确认卡片重新待复核，旧版本引用仍可解析。

引导中的草稿是程序预制示例，**不调用大模型**。引用、状态、校订和保存使用实际领域逻辑。
完整工作台支持复制任务、导回 JSON 和手动整理。公开版在线生成按钮关闭。

## 能力边界

- 全文关键词与结构化过滤，不是语义向量检索；无文字层文件不可全文搜索。
- OCR 在浏览器运行，首次使用需下载第三方引擎和语言包；复杂截图仍需人工校对。
- TXT/MD/DOCX/PPTX/HTML/PDF/常见图片有本机导入与预览支持；扫描件不会自动全部转录。
- 不提供公开云同步、私人 MCP、模型训练或在线模型生成。
- 规则能阻止部分状态误判，不能代替语义审核与用户研究。
- 浏览器清理会影响本机编辑。导出完整备份可保留原文件、关系和版本。
- 不建议在公开演示站导入真实敏感材料。自用请在自己的环境部署。

## 项目结构

```text
web/       浏览器应用、领域规则、虚构数据、作品集与引导
scripts/   静态构建、本机预览、隐私扫描
tests/    领域规则、检索、版本与本机存储测试
 docs/     架构、评估、隐私与路线图
```

前端以原生 JavaScript 实现。npm build 从已固定版本依赖中复制 PDF/DOCX/ZIP/OCR
浏览器资源与许可证；第三方大文件不直接提交仓库。静态 dist 可部署到任意根路径静态主机。
